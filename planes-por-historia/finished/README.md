# Planes finalizados

Esta carpeta contiene planes por historia que ya fueron implementados,
verificados contra criterios de aceptacion y cerrados con evidencia.

Un plan solo debe moverse aqui cuando:
- todas sus tareas esten marcadas como completadas,
- sus criterios de aceptacion tengan evidencia,
- la validacion manual o automatizada relevante haya pasado,
- y no queden bloqueos funcionales dentro del alcance vigente.
